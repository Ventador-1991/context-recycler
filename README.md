## 🚀 Why Context Recycler?

In AI-assisted software development, **85% to 90% of token consumption is not the code generated by the LLM, but the surrounding code injected into prompts for context**.

Sending whole 1,000-line dependency files burns budgets, increases inference latency, and pollutes the model's attention window.

**Context Recycler** solves this by inserting a local, zero-cost intelligence layer between your codebase and commercial LLMs:


## ⚡ The 3 Core Pillars

### 1. Deterministic AST Tree-Shaking & Dual-Mode Condensation
* **Architectural Skeleton Mode:** Extracts module imports, constants, classes, and function signatures, replacing internal function bodies with `...`. Drops tokens by **75% - 85%**.
* **Focused Edit Mode (`--target <symbol>`):** When modifying a specific function, **keeps the target function 100% INTACT with full implementation**, while skeletonizing all neighboring methods. **Zero risk of hallucinations!**
* **Whitespace & Comment Minification:** Strips boilerplate comments while preserving Python semantic indentation, types, and docstrings.

### 2. Zero-Cost Local SLM Recycler (Ollama)
* Pipes raw prompts through an offline, locally running small language model (e.g., `qwen2.5-coder:1.5b`, `llama3.2:latest`, or `qwen2.5-coder:3b`) via Ollama.
* Extracts dense, task-relevant logic before invoking commercial cloud APIs.
* **Cloud token cost: 0.00 USD.**

### 3. Semantic Chunk Buffer (SHA-256 Cache)
* Computes SHA-256 digests of code blocks and files.
* If a dependency file hasn't changed since the previous turn, returns the cached skeleton in **0 milliseconds** (`Cache Hit: True`), avoiding redundant AST parsing.

## 🛠️ CLI Usage

### 1. Architectural Mode (Skeletonize Whole File)
```bash
context-recycler src/services/database.py
```

### 2. Focused Edit Mode (Preserve Target Function 100% Intact)
```bash
context-recycler src/services/auth.py --target-symbol authenticate_user --print-code
```
> The `authenticate_user` function is preserved **entirely intact with real code**, while all sibling functions in `auth.py` are skeletonized into single-line signatures!

### 3. Local SLM Recycling via Ollama
```bash
context-recycler src/controllers/network.py --slm --task "Show routing engine configuration"
```

### 4. Setting Token Guard Thresholds
```bash
context-recycler big_context.py --threshold 4000
```

## 🐍 Python API

Integrate `context-recycler` directly into your custom agent workflows or pipelines:

```python
from context_recycler import get_smart_context, ContextRecycler, count_tokens

# 1. Focused Edit Mode
result = get_smart_context(
    file_path="backend/services/orders.py",
    target_symbol="process_payment"
)

print(f"Tokens reduced from {result['orig_tokens']} to {result['condensed_tokens']}")
print(f"Percentage saved: {result['pct_saved']}%")

# 2. Raw Text / Chunk Recycling
recycler = ContextRecycler(use_cache=True)
condensed = recycler.process(
    content="class UserService:\n    def get_user(self): ...\n    def delete_user(self): ...",
    target_symbol="delete_user"
)
```
